Trigger and state

Tap, click, Enter or Space on a native question button. Update aria-pressed and all evidence immediately. No audio autoplay.

0–180ms

180–460ms

Fast re-selection

Cancel all previous animations; display the latest evidence. Never block interaction or leave stale quotations.

Reduced motion

Immediate content and marker update, no moving marker or delayed fade. Keep the accessible relationship explanation.

Webflow + optional Rive

Webflow containers and twelve-column grids own the static page. The application module owns source evidence and media. A future Rive asset may animate only the decorative marker.

Semantic boundary

Question controls, original comments, transcript, classifications and explicit playback remain HTML. Evidence is never hidden behind a tooltip or canvas.

Live data boundary

The coordinator persists IDs and snapshots. Research does not generate. Generate is a separate credit-acknowledged action. Retry review never regenerates clips.

Complete fixture flow
